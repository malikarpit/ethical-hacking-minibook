§ 0. Syllabus, Exam Pattern and Study Blueprint

# 0.1 What the official syllabus covers

The curriculum for Ethical Hacking and Advanced Cybersecurity (DSE-3 / GE-5) under Delhi University's B.Tech CSE framework is systematically divided across 5 core pedagogical modules:

  • Unit 1: Introduction to Ethical Hacking & Cyber Laws: Core terminology (vulnerability, exploit, zero-day), ethical boundaries, Rules of Engagement (RoE), hacker taxonomy, Indian legal framework (IT Act 2000 Sections 43, 65, 66B-F, 70, DPDP Act 2025), CERT-In directives, and the 5-phase hacking lifecycle.
  • Unit 2: Network & System Security: OSI 7-layer defense, packet filtering (iptables), Stateful inspection, IDS vs IPS (Snort), VAPT methodology, packet sniffing (promiscuous mode, Wireshark, tcpdump), ARP poisoning, MITM, SUID privilege escalation, and wireless 802.11 WPA2 4-way handshake cracking.
  • Unit 3: Web Application Security & OWASP Top 10: HTTP/HTTPS protocol mechanics, SQL Injection (in-band, blind, time-based), XSS (stored, reflected, DOM), CSRF, IDOR, Server-Side Request Forgery (SSRF), file inclusion, session hijacking, and Burp Suite interception.
  • Unit 4: Advanced Cybersecurity, Malware & Cryptography: Applied cryptography (symmetric AES, asymmetric RSA, ECC, hashing SHA-256 vs bcrypt), malware analysis (static vs dynamic, packers, sandboxing), Social Engineering, and incident response.
  • Unit 5: Practical Security Operations, Cloud & Auditing: Cloud shared responsibility model (AWS/Azure), container security (Docker/K8s), SOC operations, SIEM correlation, compliance standards (ISO 27001, SOC 2, PCI-DSS), and final penetration testing reporting.

# 0.2 Exam answer pattern and marking distribution

University examination evaluators expect a structured, engineering-grade response architecture rather than unstructured prose:

Question Tier Expected Structure Mandatory Elements Target Length
10-Mark Architectural Question Introduction → Architecture Diagram → Step-by-Step Execution Mechanics → Real CLI Syntax → Countermeasures & Defense ASCII/Block architecture diagram, command flags (e.g. nmap -sS -A, iptables), exact RFC/statute citation 2.5 to 3.5 handwritten pages
5-Mark Technical Breakdown Formal definition → Comparative matrix or workflow → Concrete technical code/terminal snippet → Key limitation Clear comparison table, 3 to 4 technical bullet points, zero generic fluff 1.5 to 2 handwritten pages
2-Mark Definition / Trap Crisp 2-line technical definition + exact differentiation factor or syntax Zero storytelling; state exact distinguishing technical criterion directly 3 to 5 lines

📝 10-Mark Answer Ka Secret Formula:
1. Definitive Start: Pehle 3 line me technical definition likho.
2. Box Diagram: Pen aur scale se neat flow diagram banao (jaise WPA2 Handshake ke 4 arrows). Diagram dekhte hi examiner 4 marks pakke kar deta hai!
3. Technical Steps: Step 1, Step 2 karke points likho.
4. Real CLI Commands: Command likho flags ke sath (jaise nmap -sS -p- 192.168.1.1).
5. Defensive Shield: Answer ke last me countermeasure zaroor likho (jaise DAI, WAF, HSTS). Isse examiner ko lagta hai tum ethical hacker ho, criminal nahi!

# 0.3 Suggested learning order and schedule

To optimize cognitive retention and ensure laboratory assignments synchronize with theoretical study, follow this structured 4-week roadmap:

  • Week 1: Fundamentals, Law & Network Perimeter: Complete Unit 1 (Ethics, IT Act 2000, 5-Phase Lifecycle) and Unit 2 (OSI Layer Security, iptables, Stateful Firewalls, Snort rules). Set up Kali Linux VM.
  • Week 2: Network Sniffing, MITM & Wireless Security: Master Wireshark display filters, BPF syntax in tcpdump, ARP poisoning execution, SUID binary privilege escalation, and the WPA2 4-way handshake cracking workflow.
  • Week 3: Web Application Vulnerabilities & Exploitation: Configure Burp Suite proxy, practice SQL injection payloads, stored/reflected XSS bypasses, CSRF token validation, and SSRF attacks.
  • Week 4: Advanced Systems, Rapid Cram & Mock Exams: Review applied cryptography, malware static analysis, solve all 160 questions in the MCQ & Short Q&A simulator, and rehearse the 12 exam traps in the Last-Minute Cram module.
